# recursive-incus-stack-generator

A system for recursive Incus-based host-like environments, motivated by safer AI-agent jails, reducing 'Supply Chain Attack' risk, but also acting as a broader infrastructure pattern for isolated development and operations environments.

## Status

This repository is intended to become the public publishing space for the recursive Incus stack described in the blog-post series that starts here:

- https://weisser-zwerg.dev/posts/incus-agent-jail-recursive-ii-1-concepts/

At the moment, this is only a placeholder.

The plan is to publish the code here once the blog-post series is complete.
At that point, the series will also serve as the reference documentation for the project, explaining the concepts, architecture, and intended operating model of the published code.
